# Judge dimension: conciseness

Inspect the rendered figure before you score.
Score 1 when groups, short labels, and relationships explain the requested question without unnecessary detail.
Score 0 when copied prose, repeated explanations, or irrelevant elements obscure the structure.
Allow schema attributes and repeated stages when they explain the requested relationship.
Do not reward omission of necessary system behavior.
Use `unknown: true` when the figure or reference is insufficient.
Write the reason in Simplified Technical English.
