# Judge dimension: readability

Inspect the color and grayscale previews before you score.
Use the final dimensions from the task. Treat the previews as 150 pixels per inch.
Score 1 when labels, directions, and relationships remain clear at the final width.
Score 0 when overlap, clipping, weak contrast, or ambiguous routes prevent interpretation.
Score 0 when color loss removes a necessary distinction.
Allow different compositions when the reader can trace each necessary relationship.
Use `unknown: true` when an artifact is absent or the image tool cannot display it.
Write the reason in Simplified Technical English.
